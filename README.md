# 🌊 Tidal Launcher

A simple, polished launcher for **OG Fortnite Chapter 2 Season 3** — the iconic **Water Season**.

## About

**Tidal Launcher** is designed to make launching OG Chapter 2 Season 3 quick and simple.

The launcher features a clean glassmorphism interface with an interactive water background inspired by the Chapter 2 Season 3 map.

## Features

- 🌊 Interactive animated water background
- 🧊 Glassmorphism launcher interface
- 💻 Windows support
- 📱 iOS support
- 🤖 Android support
- ⚡ Simple one-click launching
- 🎨 Custom launcher icons
- 📐 Responsive 1920×1080 layout
- ✨ Smooth animations and transitions

## OG Fortnite

Tidal Launcher is built specifically around **Chapter 2 Season 3**, also known as the **Water Season**.

The season originally released in June 2020 and introduced the flooded Fortnite island, Aquaman, sharks, whirlpools, and many other water-themed features.
